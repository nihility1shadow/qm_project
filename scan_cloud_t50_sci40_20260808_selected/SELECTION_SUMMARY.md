# 40t 前有效收敛参数筛选

## 固定条件

- `Norb=10`，`Nel=5`，`dt=0.5 a.u.`，模拟范围 `0..50 a.u.`。
- 每次独立运行 `2,000,000` 条轨道，使用 16 个 MPI 进程。
- `0 < wc <= 10 eV`，`3e-5 <= eta <= 2.2e-4`。
- `EF=-4.5 eV`，`E0=EF-wc/2`，`E1=EF+wc/2`。
- `delE=-17.194874968839816 eV`。
- 收敛容差：轨道占据数绝对变化 `atol=1e-4`，`rtol=0`。

## 联合判据

- 从 `30..40t` 开始的持续尾段 `SCI >= 80`。
- `Q_30..40 >= 2`，避免把只有噪声或几乎无动力学的结果误判为收敛。
- `SCI >= 95` 视为强收敛。
- 完全相同的输出文件不算独立重复，本地分析器会自动排除。

## 首选参数

- `wc=6.5 eV`
- `eta=4.0e-5`
- `E0=-7.75 eV`，`E1=-1.25 eV`
- 4 次真正独立运行
- `SCI_30..40=99.7356`
- `SCI_40..50=99.3128`
- 从 `30t` 开始的持续尾段 `SCI=99.3128`
- `TCI=95.3403`
- `Q_30..40=2.2539`
- 峰值轨道 RMS 变化 `3.9014e-5`
- 粒子数最大误差 `7.70e-11`

按 `N^(-1/2)` 噪声缩放和 `sqrt(t)` 时间外推：

- `4000t` 达到 `Q=3` 约需 `2.83e8` 条轨道。
- `4000t` 达到 `Q=5` 约需 `7.87e8` 条轨道，低于十亿。

该外推只用于规划采样数量，不等于已经完成 `4000t` 实测。

## 备选参数

- `wc=5.5 eV, eta=3.5e-5`：尾段 `SCI=92.30`，但 `Q_30..40=1.80`。
- `wc=8.5 eV, eta=5.0e-5`：尾段 `SCI=80.30`，但 `Q_30..40=1.67`。

两组备选满足或接近 SCI 条件，但独立重复可辨识度不足，因此未选为最终参数。

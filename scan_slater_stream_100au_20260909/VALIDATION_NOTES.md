# 复现、历史对照与回退说明

阶段版本：v1.16-slater-poisson-100au。前一回退点：08025d65fa273d5c86cb43b4bbbfa240540e1979（v1.14-reference-only-ablation）。本阶段新增独立实验实现；原生产求解器仍保留。正式指标和全部参数见 [README](README.md) 与 [summary.json](summary.json)。

历史纯泊松 v0.93 在相同的 101 个观察时刻上，最差活跃轨道 Q 为：对连续时间 QM，47.0293；对历史网格 QM，57.2533。本次三个种子分别为 92.5097 / 89.4275 / 107.9204 和 55.5866 / 50.7229 / 62.4074。因此对连续时间 QM 的符合度更好，但对历史网格 QM 并非三次都优于旧泊松。不同基准的数据不能混用来宣称改善。

v0.93 使用 200 万前向路径、512 个反向副本和 384 个 MPI 进程；最大单进程峰值约 11.18 MiB，墙钟时间未找到。本次 Python 进程约 78 MiB，不宣称低于旧 C++ 的单进程内存。两种路径计数不是同一个计算单位，不能直接推导加速倍数。

本次墙钟和 CPU 时间覆盖求解核心，不含 Python 启动、库导入及结果写出。内存为 Windows 记录的整个进程峰值工作集，包括 Python 运行时。每个进程限制 1 个 BLAS/OpenMP 线程；正式复跑期间多个独立进程同时在本机运行，调度会影响耗时。

每条泊松路径保存 Norb×Nel 的 Slater 矩阵和核相干态，批量固定为 128；工作状态内存还包括约 Nel² 的重叠矩阵，避免分配组合数规模的完整电子波函数。当前模型的星形单体电子耦合和条件谐振子结构允许这一表示。大尺寸内核检查通过不等于大体系轨道拟合通过，也不证明 4000 a.u. 的方差仍可控。

README 中的 reproduce 命令写入单独目录供对照；绘图脚本读取归档的 final_* 数据，不会自动切换到 reproduce_*。本阶段同时归档绘图所需的历史 v0.93 原始数据；历史网格 QM 已在项目中版本管理。环境版本见每次运行的 metrics.json；依赖 NumPy、SciPy、matplotlib、psutil。

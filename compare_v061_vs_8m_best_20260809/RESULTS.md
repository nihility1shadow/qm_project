# v0.61 与旧版 800 万轨道最优参数对比

## 对比条件

两条主曲线使用完全相同的物理参数、时间网格和采样轨道数：

- `wc = 0.12 eV`
- `eta = 2.8e-5`
- `delE = -2.5 eV`
- `Norb = 10`，`Nel = 5`
- 每次运行 `ntraj = 8,000,000`
- `dt = 0.5 a.u.`，`t = 0...150 a.u.`，共 301 个时间点
- 64 个 MPI 进程

旧版代表曲线来自作业 `636040`。它是 6 条同参数旧版 800 万轨道结果中，和旧版六次平均最接近的一条，因此不是人为挑选的极端样本。新版曲线来自作业 `636268`。

## 数值检查

- 新版全部数据都是有限数，没有 `NaN` 或无穷大。
- 新版最大粒子数守恒误差为 `3.06e-10`。
- 旧版六次运行最大粒子数守恒误差为 `8.17e-11`。
- 两版时间点和输出列数完全一致。

## 同为 800 万轨道时的差异

| 时间区间 (a.u.) | 新版与旧版单次结果的 RMS 差异 | 最大绝对差异 |
|---:|---:|---:|
| 0-25 | 7.74e-6 | 4.16e-5 |
| 25-50 | 2.38e-5 | 1.38e-4 |
| 50-75 | 4.22e-5 | 2.02e-4 |
| 75-100 | 6.91e-5 | 3.68e-4 |
| 100-125 | 9.39e-5 | 5.43e-4 |
| 125-150 | 1.51e-4 | 7.33e-4 |

## 结论

1. `0-50 a.u.` 内两版的峰、谷位置基本一致，主要振荡周期没有被 v0.61 修改破坏。
2. `50 a.u.` 后两版逐渐分离。旧版出现随时间增大的漂移和噪声；新版趋向较平的有限平台，轨道 0 的损失与轨道 5-9 的增加也保持粒子数互相补偿。
3. 这不是普通随机波动：新版与旧版六次平均的差异，在各时间窗约为旧版重复运行噪声的 `1.8-5.7` 倍，说明修正后的估计公式系统性改变了长时间结果。
4. v0.61 的 4 次后向分层采样增加了开销。同配置旧版重复运行约 `3:53-4:03`，新版为 `6:53`，约慢 `1.7` 倍。
5. 本次只证明两种泊松估计器在同条件下的差异。单条新版轨迹集合不能独立估计重复收敛指标 `Q`，也不能代替同参数精确 QM；要判断长时间平台是否物理正确，仍需同参数 QM 或至少 3 次独立新版 800 万重复实验。

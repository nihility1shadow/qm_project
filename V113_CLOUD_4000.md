## Reference reuse

The deterministic reference does not depend on the sampling seed or path count.
SEP_MB_REFERENCE_OUTPUT=1 writes raw weights at every time step to
reference-observables.dat, with a parameter key and a completion checksum.
SEP_MB_REFERENCE_CACHE=<file> validates and loads this reference on the master
rank; it skips reference basis construction in path-local mode and skips all
reference wavefunction propagation. Other ranks do not load the large arrays.
Each stochastic repeat still independently samples its Poisson residual.

The key checks orbital/electron counts, initial determinant, all orbital
energies and couplings, mass, frequency, displacement, initial coherent state
and weight, dt, full time range, reference distance/count, oscillator levels,
split conventions, basis mode and propagation rank count. Seed/path count are
intentionally excluded. The complete time grid and finite weights are checked.
A canonical FNV-1a checksum of the double values catches accidental corruption;
it is an integrity check, not cryptographic authentication. Solver changes
that alter the reference must update the cache format/convention version.

- 647662 / 647663: direct/cache, 100 a.u., D3, same seed: difference 0.
- 647665 / 647667: direct/cache, 500 a.u., D1, NONZERO residual, same seed:
  difference 0; the cache read takes 0.02191 s versus fresh propagation.
- 647664: deliberately wrong 8/3 parameters for a 10/5 cache; rejected with
  exit code 3. This is an expected negative test, not a simulation failure.
- Seven local cache checks cover exact round-trip, wrong parameters, missing
  completion, altered weights, misaligned times, nonfinite values and trailing
  content. Negative zero and tiny values are preserved in the round-trip.

Reference progress is flushed every 100 a.u. Sampling progress describes only
the master's local path count; it is not a global completion percentage.
Raw reference values are weighted, not normalized final occupations. Divide
orbital weights by particle_weight/Nel for normalized reference comparisons.
The reference-only file must not be presented as the final Poisson estimate.

## Completed 4000-a.u. small-system results

All use wc=2.7 eV, eta=0.30e-6, delE=-17.194874968839816 eV and dt=0.5.
Active orbitals: 0 and 5-9. Q uses occupation changes from the initial state,
not the nearly unit baseline; every 100-a.u. window and every active orbital
are checked, and all 10 orbitals are plotted without clipping or smoothing.

The Poisson run is still noisy near 4000 a.u.: maximum orbital error 3.013e-7,
minimum estimated occupation -1.781e-7. Even the diagnostic Q=10 requirement
fails for the last windows. The largest full-electronic Fock/grid-QM difference
is 1.220e-11. This confirms the small reference solver's long-time agreement.
The full-reference job requested 1024 oscillator levels, but the program
clamps the reference to at most 512; both the run log and cache key confirm
512 actually used. Earlier stage text incorrectly quoted the request as the
actual level count. The grid QM uses 1024 spatial points, a different quantity.
However, D3 already includes 246 of 252 determinants in this small case;
D4/F512 includes all 252. The high full-reference Q does not establish a
scalable high-fit Poisson solution for 30/15.

## 30/15 production: full 0-4000 a.u. range

All jobs use 8000 steps, dt=0.5, the same physical parameters, and 128 ranks on
two nodes. Every job has a 48-hour limit, except the D2 reference pilot (12 h).
The short-test projection for reference propagation is about 16-17 hours at
F384 and about 22 hours at F512; sampling time is additional and still needs
measurement. Actual progress logs, not these projections, determine runtime.

The producers' 100-path final Poisson files are not production-quality
estimates; their purpose is the separately saved deterministic reference.
Production repeats reuse that reference. A failure of a producer prevents its
consumers from starting. Reference jobs reserve 24 GiB per node; consumers
reserve 4 GiB per node because the full reference arrays are skipped.
Final analysis must check all 30 orbitals, all 100-a.u. windows, particle number,
reference order and oscillator truncation. Repeatability Q is not absolute QM
error and cannot detect a shared systematic bias. No full 30/15 QM truth is
being claimed.
